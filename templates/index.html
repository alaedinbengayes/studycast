How it works

From your inputs to an estimate

The website sends your five answers to its server, which runs the model trained in our Google Colab notebook.

1

You enter your profile

The page checks every field first, so only complete, in-range values are sent.

2

The server loads the model

It opens model.joblib, a scikit-learn pipeline that fills blanks with training medians and one-hot encodes resource access.

3

Linear regression predicts

Each input adds or removes points. Attendance and weekly study hours have the biggest effect.

1.11Mean absolute error (points)

Limitation: a few students score far above what these five inputs suggest, and the data only covers 60–100% attendance and 1–44 study hours per week, so estimates outside those ranges are less reliable.

About

A CSCI104 Introduction to AI project

StudyCast helps students see how their study habits relate to exam results. It's a planning aid, not an official grade.

Dataset

Student Performance Factors on Kaggle: 6,607 records with study habits and exam scores.

Tools

Python, pandas, scikit-learn and Google Colab for the model. Flask and Vercel for the website.

Source code

All code and the training notebook are on GitHub.
